# Обложки и печать

Добавлены пять собственных векторных обложек по мотивам палитры и композиций публичного сайта comabooks.org: «Сад роз», «Серебряные ветви», «Бордовый бархат», «Зелёный мрамор», «Золотой вечер». Это авторские стили, а не копии фотографий/текстур сайта. Три прежних идентификатора сохранены.

## Для клиента
1. Создать книгу и выбрать миниатюру обложки. Обычный выпадающий список также работает, в том числе без JavaScript.
2. Заполнить страницы и фотографии.
3. В «Мои книги» доступен только «Скачать PDF» для чтения. Комплект для типографии доступен исключительно в админке.
4. В карточке книги администратора есть отдельная кнопка скачивания печатного комплекта.

## Печатный комплект
- 01-interior.pdf: внутренний блок A5, страницы по порядку, зеркальные поля.
- 02-cover-front.pdf и 03-cover-back.pdf: плоские обложки с вылетами 3 мм и TrimBox.
- READ-ME-print.txt: инструкции, размеры, ориентация двусторонней печати, предупреждения о фотографиях.
- print-spec.json: машинно-читаемые параметры и число страниц.
- 04-cover-spread.pdf появляется, только если типография предоставила ширину корешка.

По умолчанию: 148 × 210 мм; внутреннее поле 22 мм, внешнее 16 мм, верхнее 18 мм, нижнее 20 мм. Внутренний блок имеет чётное количество страниц. Пустые страницы сохраняют стороны разворота. В читательском PDF дополнительно есть обложки и их пустые внутренние стороны.

Печатать внутренний блок отдельно от обложек, в масштабе 100%, без подгонки, с переворотом по длинной стороне. Спуск полос выполняет типография.

## Параметры
В book_shop/settings.py словарь BOOK_PRINT задаёт размеры в миллиметрах. spine_mm=None означает, что полный разворот обложки не строится. Число, например 12, допустимо только после подтверждения типографией.

Полный разворот рассчитан на плоскую мягкую обложку. Для твёрдого переплёта типография должна предоставить размеры расставов, загибов и крышки. Эти размеры нельзя вывести только из числа страниц.

Файлы используют RGB и встроенные шрифты, но не заявляются как PDF/X. Цветовой профиль, бумагу и пробный отпечаток согласовывают с типографией. Фотографии с эффективным разрешением менее 200 dpi отмечаются в отчёте; для качественной печати ориентир 300 dpi. Недоступные изображения также отмечаются.

## Разработка и запуск
- Установить requirements.txt (добавлен pypdf).
- python manage.py migrate
- python manage.py test config
- python manage.py generate_cover_assets — пересоздать SVG после изменения векторного рисунка в config/cover_designs.py.
- Перезапустить работающий сервер после обновления Python-кода.

Шрифт Lora встроен в PDF и доступен в браузере локально; лицензия OFL находится рядом с файлами шрифта. Для генерации PDF не требуются сетевые запросы.

## Проверено
Восемь регрессионных тестов: варианты обложек, длинный титульный лист, буквальная обработка пользовательской разметки, зеркальные поля, фотографии, вылеты, корешок и права доступа.
Образец и стрессовый PDF визуально просмотрены после рендеринга. Коллекция проверена в браузере, включая мобильный экран. Миграция 0009 применена к локальной базе после резервного копирования; содержимое книг не изменялось.
